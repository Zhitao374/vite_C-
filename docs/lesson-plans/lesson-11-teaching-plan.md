## 🎯 五大核心节点速览

### 节点 1：钩子 · 从排队到棋盘（0:00-0:05）
- **【教师操作】**：画出五子棋棋盘，提问如何记录坐标。
- **【关键台词】**：“一维数组是一条线，但现实中有很多面。我们需要能给程序建立‘平面坐标’的新武器，这就是二维数组。”
- **【学生状态】**：从生活经验出发，理解学习二维数组的必要性。

### 节点 2：第一次冲突 · 双重循环迷魂阵（0:15-0:25）
- **【教师操作】**：让学生自己写双重循环打印矩阵。
- **【关键台词】**：“为什么你的数字排成了一列？因为外层应该是行，内层是列，你写反了！外层走一步，内层要跑一整圈。”
- **【学生状态】**：被循环顺序折磨，深刻记住“外行内列”。

### 节点 3：核心揭示 · 电影院查票法（0:25-0:35）
- **【教师操作】**：用电影院座位类比，画图演示 `i` 和 `j` 的变化。
- **【关键台词】**：“`a[2][3]` 是 3排4列，不是 3列4排。外层 `i` 是排数，内层 `j` 是座位号。查完一整排，再查下一排。”
- **【学生状态】**：将抽象的双重循环与具体场景绑定，形成肌肉记忆。

### 节点 4：第二次冲突 · 转置覆盖惨案（0:45-0:55）
- **【教师操作】**：演示 `a[i][j] = a[j][i]` 的原地转置，导致数据全部丢失。
- **【关键台词】**：“你直接把右边的值赋给左边，那左边的值呢？被覆盖了！等你反过来想用原来的值时，它早就不在了。”
- **【学生状态】**：震惊，理解了为什么交换必须用中间变量，或者必须开新数组。

### 节点 5：收束 · 爆栈急救与对角线（1:15-1:30）
- **【教师操作】**：强调二维大数组开在 `main` 外的铁律；板书对角线公式。
- **【关键台词】**：“二维数组比一维大得多。`1000x1000` 放在 `main` 里必死无疑。记住：主对角线 `i==j`，副对角线 `i+j==n-1`。”
- **【学生状态】**：带着公式和防崩技巧，准备迎接二维实战。

## 🚑 机房急救卡
1. **现象**：地图题运行直接闪退（RE）。
   **解药**：检查是不是写了 `int map[1005][1005];` 在 `main` 里。把它剪切到 `main` 外面变成全局变量。
2. **现象**：矩阵行列输出反了。
   **解药**：检查你的双重循环是不是外层写了 `j`。改成外层 `i`（行），内层 `j`（列）。
