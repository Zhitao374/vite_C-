## 二、5 个核心节点速览

### 节点 1 · 钩子（0-5 分钟）

**【教师操作】**
现场敲 `cout << 5 / 2;`，让学生看到输出 2。

**【关键台词】**
- 「5 除以 2 等于几？」→「数学里是 2.5，C++ 里呢？」
- （敲代码）「啊！输出的是 2！」
- 「计算机里没有纯粹的数学，只有类型和数集的规则。」

**【学生状态】**
先答「2.5」，看到 2 时 8/10 会「咦」一声。

---

### 节点 2 · 第一次冲突（20-28 分钟）

**【教师操作】**
演示 `int a = 5, b = 2; double c = a / b;`，逐步走查 c 的值。

**【关键台词】**
- 「有的同学心想：『我用 double 接不就行了？』」
- 「好，我们试试。c 是多少？」（学生：2.5！）
- （按下一步）「**c 是 2.0**。小数去哪了？」
- 「因为先算等号右边，`int / int` 还是 `int`，然后才转 double。」

**【学生状态】**
从「我懂了」→「咦？」→「原来如此」。本讲最强认知落差。

---

### 节点 3 · 核心揭示（42-50 分钟，含 T1 魔法）

**【教师操作】**
演示 `0.1 + 0.2`：先用 cout 输出（骗人），再用 `printf("%.17f")` 扒底裤。

**【关键台词】**
- 「0.1 加 0.2，数学里等于 0.3，对吧？」
- （演示 cout）「你们看，**0.3**。完美。」
- （停 2 秒）「但 cout 是个骗子。老师用 printf 这个超纲魔法，把 17 位小数全扒出来。」
- （演示 printf，屏幕显示 0.30000000000000004）
- 「看到了吗？**多了一条长长的尾巴！**」
- 「因为二进制里 0.1 是无限循环的，内存只能截断。」

**【学生状态】**
全班倒吸凉气（8/10 会「哇」），10/10 记住 0.30000000000000004。

---

### 节点 4 · 迁移练习（57-84 分钟，三段）

**【教师操作】**
- **4a（char）**：演示 `(int)'A'` → 65，讲 ASCII 化妆术
- **4b（大小写）**：练习 `char(c-32)`
- **4c（bool + 圆的面积）**：演示 `cout << true;` → 1；做圆的面积练习

**【关键台词】**
- 「char 看起来住字母家族，但它其实是数字的化名 —— 'A' 的真名是 65。」
- 「小写比大写大 32，所以 `char(c-32)` 一行搞定。」
- 「true 就是 1，false 就是 0 —— 第 4 讲学 if 全靠它。」

**【学生状态】**
从「字母怎么会是数字」→「哦，ASCII 化妆术」→「我会写了」。

---

### 节点 5 · 收束（84-105 分钟）

**【教师操作】**
- 初赛渗透（84-88）：ASCII 必背
- 小测（88-94）
- 总结（94-98）：「计算机不是数学，它有边界」
- 预告（98-101）：「下一讲学 if，但浮点数怎么比？悬念留给你」

**【关键台词】**
- 「今天两次震撼告诉我们同一件事：**计算机不是数学，它有边界**。」
- 「带着一个问题离开：浮点数不能直接比，那 if 遇到浮点数怎么办？」

**【学生状态】**
带着「浮点数怎么比较」的悬念离开。

## 三、机房急救卡

| 易错现象 | 学生表述 | 解药 |
|---|---|---|
| 输入小数用逗号 | 「我输入 3,14 为什么错了？」 | **小数用点，不用逗号**：`3.14` ✅，`3,14` ❌ |
| cout 输出小数位数不对 | 「0.1+0.2 输出 0.3，不是说会出错吗？」 | cout 默认精度会隐藏误差，用 printf 才看得到 |
| 忘记 (double) | 「我写了 `9/5` 为什么是 1？」 | 两个整数相除还是整数，必须 `9.0/5.0` 或 `(double)9/5` |
| `char c = "A"` 报错 | 「我用双引号怎么不行？」 | **char 用单引号**，双引号是 string |
| `(int)3.99` 得到 3 | 「3.99 不是四舍五入到 4 吗？」 | 强转是**截断**，不是四舍五入 |
