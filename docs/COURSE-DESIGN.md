## 三、教学设计原则

### 3.1 "问题驱动" 优先

**不先给定义** —— **先问"为什么需要它"**。

**例**（lesson-02）：
- ❌ 直接讲"变量是什么"
- ✅ 先问"没有变量，程序怎么存数据？"—— 用 `origin` 讲"从内存地址到名字的演进"

### 3.2 三类知识分层

| 类型 | 呈现方式 |
|---|---|
| **概念** | origin / dialog / grid |
| **代码** | code-split / evolution |
| **练习** | level-map / quiz |

### 3.3 "伏笔 - 回收" 跨讲联动

**每讲埋伏笔**（如"0 和 1 → 第 22 讲"）—— **后续讲回收**。

**标记**：数据里用 `🔮 伏笔` / `🔮 回收伏笔`。

**自动扫描**：`generate-index.js` 生成"伏笔清单"。

### 3.4 每讲"三要素"

**每讲必须有**：
1. **一个核心概念**（`core`）—— 一句话
2. **3-4 个子知识点**（`points`）—— 逐轮讲
3. **一个跨讲联结**（`fore`）—— 埋或收

### 3.5 教学节奏模板

```
回顾 → 目标 → 地图 → 概念 → 代码 → 练习 → 小测 → 总结 → 作业 → 预告
```

**约 25-35 页 / 讲** —— 一节课 45 分钟或学生自学 1.5 小时。

## 九、教学质量的判断标准

**做对了**：
- 学生**能看懂为什么**（不只"是什么"）
- 学生**能动手**（每讲 3 道练习）
- 学生**有印象**（伏笔 / 故事 / 图片）
- 学生**有方向**（知道下一步学什么）

**做错了**：
- 只堆知识点，不问"为什么"
- 页数多但节奏乱
- 每页都"一样密"或"一样空"
- 学生学完记不住核心
