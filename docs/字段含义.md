# C++ 课程系统 Slide 数据字段完全指南

> 本文档梳理了前 7 讲（新格式）中所有 Slide 类型的 `data` 字段规范。
> **核心规则**：`title` / `subtitle` / `chapterTag` 放在**最外层**，业务内容全部放在 `data` 里。所有支持 `v-html` 的文本字段均可写 HTML 标签（如 `<b>`、`<code>`、`<br>`）。

---

## 🌟 全局通用字段（所有 Slide 通用）

除了各个组件自带的字段，`SlideShell.vue` 和 `useSlideSteps.js` 接管了以下通用字段：

| 字段名 | 类型 | 含义 | 步数影响 |
| :--- | :--- | :--- | :--- |
| `data.intro` | String | 课堂导入（大段文字）。只在第 1 步作为大框显示，后续步骤收成右上角“💡课堂导入”按钮。 | 不占步数 |
| `data.extra` | Object | 页面底部的补充卡。如果在数据中写了，会自动在**最后一步**显示。<br>包含 `title`、`desc`、`image`、`variant`。 | 自动 +1 步 |
| `data.extra.variant` | String | `'card-primary'`（蓝底折叠）、`'card-glow'`（橙底折叠）、`'flat'`（静态注脚，无折叠）。 | - |

> **⚠️ 关于 footer**：`footer` 概念已全面废弃。原 `footer` 文本请统一迁移至 `data.extra` 并设置 `variant: 'flat'`。

## 一、基础展示版式

### 1. `cover`（封面）
用于每一讲的第一页。
- **`data.accentWord`** (String): 标题中需要用高亮颜色强调的词。
- **`data.meta`** (Array): 封面底部的两行小字（如：课程名称、讲次）。

### 2. `transition`（过渡页）
用于大章节之间的切换。
- **`data.note`** (String): 页面底部的补充小字。
- **`data.previous`** (String): （可选）显示在顶部的“刚才讲了：xxx”回顾。

### 3. `ending`（结束页）
用于每一讲的最后一页。
- **`data.slogan`** (String): 底部的口号。
- **`data.extra`**: 可以写一个 `card-glow` 的 extra，作为下节预告的华丽卡片。

---

## 二、排版与图文版式

### 4. `grid`（卡片网格）
最常用的排版，支持 1~8 个卡片自动排列。
- **`data.cards`** (Array):
  - `icon` (String): Emoji 图标。
  - `number` (String): 大号数字（与 icon 二选一）。
  - `title` (String): 卡片标题。
  - `link` (String): （可选）如果填写，标题会变成可点击的外链。
  - `desc` (String): 卡片正文，支持 HTML。

### 5. `split`（左右分栏）
用于对比两段文字，或左图右文、左代码右文。
- **`data.cols`** (Number): 分栏数量（2~4，默认 2）。
- **`data.stepped`** (Boolean): 是否按分栏一步步显示（默认 false 全部显示）。
- **`data.panes`** (Array):
  - `title` (String): 分栏标题。
  - `icon` (String): Emoji 图标。
  - `image` (Object): 如果传图片，格式为 `{ src, caption, credit }`。
  - `codeFile` (String): 如果传代码，指向 `.cpp` 路径。
  - `snippet` (String): 代码截取标记。
  - `items` (Array): 如果传列表，传 `[{ title, desc }]`。

### 6. `flow`（流程图）
横向排列的节点与箭头。
- **`data.rows`** (Array): 二维数组，支持多行流程图。每一行包含：
  - `icon` (String): 图标。
  - `label` (String): 主标题。
  - `sub` (String): 副标题。
  - `glow` (Boolean): 是否高亮（橙色边框）。

### 7. `timeline`（时间线 / 步骤条）
左侧带竖线的列表，常用于上节回顾或作战地图。
- **`variant`** (String, **在 slide 顶层**): `'review'`（蓝色回顾）或 `'map'`（路线图）。
- **`data.items`** (Array):
  - `icon` (String): 图标。
  - `badge` (String): 右上角的标签（如“第一站”）。
  - `title` (String): 标题。
  - `desc` (String): 描述。
  - `points` (Array): 若干条子项目（自动加 ▸ 符号）。

### 8. `quote`（金句总结）
左侧大字引语，右侧要点列表。
- **`data.text`** (String): 左侧大字引语。
- **`data.author`** (String): 引语出处。
- **`data.points`** (Array): 右侧的要点数组（每项一句）。
- **`data.highlight`** (Object): 底部高亮卡片 `{ title, desc }`。

### 9. `radial`（放射状导图）
中心一个圆，四周散布分支。
- **`data.center`** (String): 中心文字。
- **`data.items`** (Array): 散落的文字节点 `[{ text, pos }]`。

## 三、交互与练习版式

### 10. `dialog`（对话气泡）
师生对话场景。
- **`data.lines`** (Array):
  - `who` (String): `'student'`（左边）或 `'robot'`（右边）。
  - `text` (String): 对话内容（支持 HTML）。

### 11. `quiz`（课堂小测）
支持单题或多题轮播，自动计算步数。
- **`data.questions`** (Array):
  - `question` (String): 题干。
  - `questionCode` (String): （可选）题干里的代码块。
  - `options` (Array): `[{ label: "A", text: "xxx", correct: true }]`。
  - `optionLayout` (String): `'horizontal'` (短选项横排)、`'two-cols'` (中长选项双栏)、`'vertical'` (代码/长文本竖排)。
  - `analysis` (String): 题目解析。
  - `source` (String): 来源标签。
  - `difficulty` (Number): 难度星级（1~5）。

### 12. `level-map`（实战练习）
大厂 OJ 风格的题目页面，**支持分步思考**。
- **`data.question`** (Object): `{ desc, timer }`。
- **`data.hints`** (Array): 右侧的提示语数组（默认按步数逐渐显示）。
- **`data.steps`** (Array): （可选）**开启分步思考**，如果有此字段，代码会随步骤逐渐显示。结构见下方“代码步骤通用结构”。
- **`data.answer`** (Object): 最终代码 `{ codeFile, snippet }`。
- **`data.analysis`** (Object): 最终解析 `{ title, desc }`。

### 13. `compare`（对比）
左右两栏对比“错与对”。
- **`data.neutral`** (Boolean): 开启中性模式（不暗示对错，蓝紫配色）。
- **`data.splitStep`** (Boolean): 是否先出左边，再出右边。
- **`data.groups`** (Array): `[{ leftLabel, wrong, rightLabel, right }]`。

---

## 四、概念引入版式

### 14. `origin`（概念起源）
问题 -> 演进 -> 总结。
- **`data.problem`** (Object): `{ title, points: [], visual }`（红色背景的问题区）。
- **`data.evolution`** (Array): `[{ icon, era, title, desc }]`（历史演进节点）。
- **`data.summary`** (Object): `{ title, desc, code }`（绿色背景的结论区）。

### 15. `pitfall`（避坑指南）
- **`data.cases`** (Array): `[{ icon, scene, what, why, fix }]`。

### 16. `decision`（决策指南）
- **`data.signals`** (Array): `[{ icon, keyword, desc }]`（黄色信号卡）。
- **`data.conclusion`** (Object): `{ title, desc }`（绿色结论卡）。

### 17. `big-number`（大数字）
- **`data.number`** (String): 大数字（如 `"2147483647"`）。
- **`data.unit`** (String): 单位（如 `"约 21 亿"`）。
- **`data.card`** (Object): `{ title, desc }`（右侧说明卡片）。

### 18. `glossary`（术语表）
- **`data.words`** (Array): `[{ word, pron, cn, origin, category }]`。

---

## 五、代码演示版式（含分步思考）

所有代码组件，只要用到 `steps` 字段，底层就会复用 `CodeStepPanel` 进行逐步揭示。

### 19. `code-split`（常规代码展示）
左侧代码，右侧注解与运行结果。
- **`data.codeFile`** (String): 代码路径。
- **`data.snippet`** (String): 截取标记名称。
- **`data.annotations`** (Array): `[{ line, title, desc }]`（右侧的行号注解）。
- **`data.output`** (String): 终端运行结果。

### 20. `code-walkthrough`（变量透视）
演示代码运行过程中的变量变化。
- **`data.steps`** (Array): 结构见下方“代码步骤通用结构”。

### 21. `evolution`（代码演化）
演示代码从无到有、从不完善到完善的演进过程。
- **`data.steps`** (Array): 结构见下方“代码步骤通用结构”。

## 🛠️ 附：代码步骤通用结构（`steps` 数组格式）

用于 `level-map`、`code-walkthrough`、`evolution`，由 `CodeStepPanel` 统一渲染。

```javascript
steps: [
  {
    title: "步骤标题（如：思路 1 / 变量更新 / 添加循环）",
    desc: "步骤详细说明，支持 HTML。（也可以写 note，效果一样）",
    
    // 代码控制部分：
    highlightLines: [9, 10],  // 当前高亮哪几行
    line: 9,                  // （简写）只高亮单行，等价于 highlightLines: [9]
    
    hiddenLines: [11, 12],    // 隐藏哪些行，用于分步揭示代码
    placeholder: "// ...代码待补充", // 隐藏区域显示的占位文字
    
    // 特殊卡片展示（按需选填）：
    expression: "a = b + c",  // 用于 Evolution 顶部的大号公式
    vars: {                   // 用于 Walkthrough 的变量面板
      a: "10",
      b: "<span style='color:red'>20</span>"
    },
    stack: [                  // 用于 Walkthrough 的调用栈面板
      { label: "fact(3)", value: "执行中", done: false }
    ]
  }
]
```

### 💡 分步时间轴计算公式（`LevelMapSlide`）
如果在 `level-map` 中同时写了 `hints` 和 `steps`：
1. **题干**（第 1 步）
2. **提示**（第 2 ~ N 步）
3. **代码第一步 + 步骤 1 说明**（第 N+1 步）
4. **代码第二步 + 步骤 2 说明**（第 N+2 步）
...以此类推。
