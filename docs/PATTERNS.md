# 版式选择指南

## 快速对照表

| 教学场景 | 推荐版式 | 避免 |
|---|---|---|
| 课程开场 / 章节切换 | cover / transition | dialog |
| 概念对比 | compare / split | dialog |
| 概念引入（对话式） | dialog | 连续 2+ dialog |
| 代码逐行讲解 | code-split | — |
| 代码执行过程 | evolution / code-walkthrough | — |
| 概念历史 / 由来 | origin / timeline(history) | — |
| 常见错误 | pitfall / compare | — |
| 决策判断 | decision | — |
| 数据展示 | big-number / grid | — |
| 流程步骤 | flow | — |
| 练习题 | level-map | — |
| 课堂小测 | quiz | — |
| 知识回顾 | timeline(review) / quote | — |
| 术语表 | glossary | — |

## 每讲节奏模板（30 页）

- 1 页 cover
- 1 页 timeline(review)
- 1 页 grid（目标）
- 1 页 timeline(map)
- 4-6 页 概念主体（dialog ≤ 3，其余用 split / compare / grid）
- 3-4 页 代码主体（code-split / evolution）
- 2-3 页 level-map（练习）
- 1 页 dialog（初赛渗透）
- 1 页 quiz
- 1 页 quote（总结）
- 1 页 grid（作业）
- 1 页 radial（预告）
- 1 页 dialog（答疑）
- 1 页 glossary
- 1 页 grid（知识清单）
- 1 页 ending

## dialog 使用上限

- 每讲 ≤ 3 个 dialog
- 不允许连续 2 个 dialog
- 不允许连续 2 个 timeline

## 检查清单（写完一讲后过一遍）

- [ ] dialog ≤ 3 个
- [ ] 没有连续 2 个同类型页
- [ ] 每讲的 5 个阶段都有覆盖（概念 / 代码 / 练习 / 小测 / 总结）
- [ ] 伏笔都有对应回收
- [ ] glossary 词条 6-12 个
